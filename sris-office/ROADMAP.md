# Roadmap

- **0.1.0** Shell, rich text, `.sri`, PDF/HTML export, print, find/replace, zoom, themes, autosave.
- **0.2.0** Real pagination, headers/footers, dynamic page numbers, images (insert/resize/caption).
- **0.3.0** Tables, document outline / navigation pane, Table of Contents from heading styles.
- **0.4.0** DOCX import/export (documented limits), ODT import/export.
- **0.5.0** Footnotes, captions, cross references, List of Figures/Tables.
- **0.6.0** Equations (Unicode + LaTeX input), bibliography/citations, thesis template.
- **0.7.0** Spell-checking providers (English first, Tamil dictionary), settings dialog.
- **0.8.0+** Packaging: `.deb`, AppImage, Flatpak; accessibility audit.
- **1.0.0** Stable Writer. Later: Calc, Impress, Draw.
