================================================================================
                         INSTALLATION & USAGE
================================================================================

INSTALLATION (3 steps):
1. tar -xzf qec_rmt_studio_complete.tar.gz
2. cd qec_rmt_studio
3. pip install -e ".[dev]"

LAUNCH GUI:
   qec-rmt-studio

RUN TESTS:
   pytest tests/ -v --cov=qec_rmt

USE IN PYTHON:
   from qec_rmt.core import DataSanitizer, RMTEngine, QECEngine
   
   sanitizer = DataSanitizer()
   rmt = RMTEngine()
   qec = QECEngine(d=3)
   
   data_clean, health = sanitizer.sanitize_array(your_data)
   results = rmt.process_series(data_clean)
   for r in results:
       if r.validity:
           e_l = qec.compute(r.brody_w).E_L

================================================================================
                      MATHEMATICAL FRAMEWORK
================================================================================

All 9 core formulas are implemented and documented:

1. STANDARDIZATION: ĥx_i = (x_i - μ) / σ
2. HANKEL EMBEDDING: H_ij = x̂_(i + jτ)
3. WISHART MATRIX: W = (1/p) H H^T
4. LINEAR MAPPING: x_i = 2(λ_i - λ_min)/(λ_max - λ_min) - 1
5. LEGENDRE UNFOLDING: N̄(x) = Σ a_n P_n(x)
6. NORMALIZED SPACINGS: s_i ← s_i / <s>
7. BRODY DISTRIBUTION: P(s;w) = c_w(1+w)s^w exp(-c_w s^(1+w))
8. CHAOTICITY→NOISE: p_phys(w) = p_0(1 + α w^β)
9. SURFACE CODE SCALING: E_L ≈ C(p_phys/p_th)^((d+1)/2)
